Exercicio:

Simular um banco de dados utilizando Excel / Google Sheets / Office 365

Você deve simular todo o banco de dados para uma biblioteca

Todo usuário de uma biblioteca, além de ter uma conta, pode pegar livros emprestado. 
Os usuários devem ter uma tabela própria, assim como os livros e também os empréstimos.
Não se esqueça que empréstimos tem data para devolução. Também é interessante ter um
registro se estão atrasados ou não. Cada empréstimo é ligado a um usuário e um livro.
